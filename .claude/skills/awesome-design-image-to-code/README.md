# Awesome Design Image to Code Skill

## Purpose
Converts design images (screenshots, mockups, wireframes) into HTML/CSS code. This skill helps you transform visual designs into functional web code quickly and accurately.

## Usage
When you have a design image (PNG, JPG, SVG, etc.) and need to generate corresponding HTML/CSS code, invoke this skill. It analyzes the visual elements and produces clean, semantic code that matches the design.

## How It Works
1. Upload or reference a design image
2. The skill identifies layout structures, typography, colors, spacing, and components
3. Generates HTML structure with appropriate semantic elements
4. Creates CSS with precise measurements, colors, and styling
5. Optionally provides React/Vue/Angular variants
6. Includes responsive breakpoints when detectable

## Features
- Layout detection (grid, flexbox, absolute positioning)
- Typography analysis (font families, sizes, weights, line heights)
- Color extraction with exact hex/RGB values
- Spacing and padding/margin measurement
- Component identification (buttons, cards, forms, navigation)
- Responsive design inference
- CSS optimization suggestions
- Accessibility considerations (semantic HTML, ARIA hints)

## Output Formats
- HTML5 + CSS3 (vanilla)
- React components with CSS modules or styled-components
- Vue.js single-file components
- Angular components
- Tailwind CSS utility-first approach
- Bootstrap-compatible markup

## Best Practices
- Start with high-fidelity mockups for best results
- Consider providing multiple states (hover, active, focus) if visible
- Review generated code for semantic correctness
- Optimize for performance (avoid over-specific selectors)
- Consider using CSS variables for theme consistency

## Example Workflow
1. Provide landing page mockup image
2. Skill identifies: header, hero section, feature cards, testimonials, footer
3. Generates semantic HTML: header, nav, main, section, footer
4. Creates CSS with exact colors, spacing, and responsive breakpoints
5. Optional: Adds interactive states for buttons and links

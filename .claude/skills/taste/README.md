# Taste Skill

## Purpose
Generates color palettes based on mood or emotion. This skill helps you create harmonious color schemes that evoke specific feelings or atmospheres for your designs.

## Usage
When you need to create a color palette for a project, invoke this skill and specify the desired mood or emotion. The skill will provide you with a curated color palette including hex codes, RGB values, and usage suggestions.

## How It Works
1. Specify the mood/emotion you want to convey (e.g., "calm", "energetic", "professional", "mysterious")
2. The skill analyzes color psychology principles
3. Returns a balanced palette with primary, secondary, and accent colors
4. Includes accessibility considerations and usage guidelines

## Example Output
For mood "calm and trustworthy":
- Primary: #2563EB (Blue) - Trust, stability
- Secondary: #64748B (Slate) - Neutral balance
- Accent: #10B981 (Emerald) - Growth, harmony
- Background: #F8FAFC (Soft white)
- Text: #1E293B (Dark slate)

## Best Practices
- Consider color blindness accessibility
- Test contrast ratios for text readability
- Use the 60-30-10 rule (primary-secondary-accent)
- Adapt palettes for different cultural contexts

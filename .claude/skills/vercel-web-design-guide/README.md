# Vercel Web Design Guide Skill

## Purpose
Checks your code against Vercel's design principles and best practices for web development. This skill helps ensure your projects follow Vercel's recommendations for performance, accessibility, and user experience.

## Usage
Invoke this skill when you want to validate your HTML, CSS, JavaScript, or React code against Vercel's web design guidelines. The skill will analyze your code and provide specific feedback on areas for improvement.

## What It Checks
- Performance optimization (bundle size, lazy loading, image optimization)
- Accessibility compliance (ARIA labels, semantic HTML, color contrast)
- Responsive design principles
- SEO best practices
- Code organization and maintainability
- Vercel-specific optimizations (ISR, edge functions, image component)

## How to Use
1. Point the skill to your code files or paste code snippets
2. Specify what type of validation you want (performance, accessibility, etc.)
3. Receive actionable feedback with specific line numbers and suggestions

## Example Feedback
- "Consider using Vercel's Image component for automatic optimization"
- "Add ARIA labels to improve screen reader accessibility"
- "Implement lazy loading for below-the-fold images"
- "Use semantic HTML elements (header, nav, main, section, footer)"
- "Optimize CSS by removing unused styles"

## Vercel Design Principles
1. Performance First
2. Accessibility by Default
3. Developer Experience Matters
4. Progressive Enhancement
5. Mobile-First Approach

# Portfolio

This is a personal portfolio website built with React, Vite, and Tailwind CSS.
You can click in the link below to view my portfolio:
https://www.kohinoordallakoti.com.np/

## Features

- Modern, premium design with golden ratio typography
- Responsive layout
- Dark/light theme support
- Interactive cloud background
- Showcase of featured projects with filtering
- Detailed project modals
- Contact form with copy-to-clipboard functionality

## Projects

- Controller Poster (UI/UX Design)
- Animated Shoes Ad (UI/UX Design)
- ITKhoji (Full-stack Web Application) - Job portal for IT professionals
- BeautyKrat (Full-stack E-commerce) - Online cosmetic store

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Design System

- Color variables defined in `src/styles/index.css`
- Typography scale based on golden ratio
- Subtle surface styling with `.net-panel` and `.net-panel-sm`
- Responsive breakpoints at 768px
